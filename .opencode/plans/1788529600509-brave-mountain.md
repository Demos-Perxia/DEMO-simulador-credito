# Plan de despliegue Docker para API

## Objetivo
Crear un contenedor multi-stage para `simulador-libranza-api`, compatible con Render.

## Implementación
1. Crear `simulador-libranza-api/Dockerfile` usando SDK y runtime .NET 10.
2. Restaurar y publicar `src/CuotaClara.Api` junto con sus proyectos referenciados.
3. Exponer el puerto 8080 y configurar Kestrel mediante `ASPNETCORE_URLS=http://+:8080`.
4. Ejecutar en producción con `CuotaClara.Api.dll`.
5. Agregar `.dockerignore` para excluir artefactos locales, pruebas y archivos no requeridos del contexto.
6. Ajustar CORS con la URL pública del frontend de Netlify mediante la variable `Cors__AllowedOrigins__0` en Render.

## Verificación
- `docker build -t cuota-clara-api -f Dockerfile .` desde `simulador-libranza-api`.
- `docker run --rm -p 8080:8080 cuota-clara-api`.
- Consultar `GET /api/v1/catalogs/activities`.
- Verificar desde el frontend publicado que la API acepta su origen configurado.
